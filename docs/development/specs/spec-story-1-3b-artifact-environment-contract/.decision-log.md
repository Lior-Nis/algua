# Decision log

## 2026-09-27 — Initial distillation

- Separated bundle, environment and manifest identity. The bundle cannot contain its own digest and
  does not change when only the interpreter or dependency environment changes.
- Limited preparation to the current clean full-OID `HEAD`. Arbitrary historical refs would require
  a separate qualification-selection and user-intent contract; offline recovery needs no Git.
- Chose Git blob export over checkout reads so the recorded commit, not mutable filesystem content,
  supplies executable source and environment build inputs.
- Reused the existing immutable `deployment_artifacts` ledger and placed frozen-specific typed data
  in canonical `manifest_json`; no schema migration is justified for this slice.
- Kept the existing integer planner protocol stamp for column compatibility and added explicit
  `planner_boundary_version` and named `frozen_wire` identities inside the frozen manifest. Story
  1.3c will implement the wire codec; Story 1.3b only stamps the agreed route.
- Selected a relocatable uv-created environment with copied package files and exact current
  interpreter identity. Local, editable, path, VCS, project and workspace installs are forbidden.
- Permitted only the narrowly validated interpreter links created by the environment tool. Source
  bundles permit no links; all other environment links and all hardlinked package files fail.
- Defined publication as staged build, canonical verification, sealing, fsync and locked no-overwrite
  rename. A complete unreferenced object after a database failure is safe and reusable.
- Made prepare mutating but non-activating, and verify offline/read-only. Both expose only canonical
  relative locators and bounded diagnostics.
- Rejected model assets before path dereference. This preserves the current source-only paper lane
  and avoids inheriting the working-tree descriptor's absolute-path asset representation.

Self-validation passed. Every capability has an observable success condition; the companion closes
the digest, inventory, environment, publication, persistence, CLI and failure semantics; authority
and later Story 1.3c/1.3d behavior are explicit non-goals. No unresolved choice is delegated to the
implementer.
