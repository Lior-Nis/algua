# Research Run 20260814-130001

Thesis: liquid names with the sharpest short-horizon adjusted-price selloffs relative to peers may rebound over the next few sessions, particularly when the selloff does not resemble an earnings-style one-day volatility shock.

All evaluations used PIT universe `liquid10`, immutable bars snapshot `b1fb94b29fcb7601`, `adj_close`, the window `2015-01-01` through `2026-08-14`, four walk-forward windows, a 20% untouched holdout, default transaction costs, and `rank_by=mean_sharpe`. The bars snapshot passed `algua data verify`. No relaxation flags or human-only paths were used.

## 1. Shock-veto peer selloff rebound

Strategy: `shock_veto_peer_selloff_rebound`

Hypothesis: the sharpest five-session peer-relative selloffs rebound, but an extreme daily adjusted return relative to the name's trailing 63-session robust volatility scale identifies an event-style shock that should be excluded.

Base parameters: `selloff_lookback=5`, `shock_multiple=3.5`, `volatility_lookback=63`; `top_k_equal_weight` with `top_k=3`.

Full backtest: total return `153.91%`, CAGR `8.37%`, Sharpe `0.5500`, max drawdown `-24.19%`, turnover `895.33`.

Walk-forward: mean Sharpe `0.6038`, minimum Sharpe `0.4716`, standard deviation `0.1924`, positive windows `100%`. Window Sharpes were `0.5225`, `0.4716`, `0.9355`, and `0.4857`.

Sweep: `selloff_lookback=[3,5]` and `shock_multiple=[2.5,3.5]`, four measured combinations. The best combination was `selloff_lookback=5`, `shock_multiple=2.5`, with mean Sharpe `0.7638`, minimum Sharpe `0.3269`, and all windows positive. The base configuration ranked second with mean Sharpe `0.6038` and a better worst-window Sharpe of `0.4716`; both three-session variants had a negative worst window.

Preview gate: binding floor passed and the scratch strategy reached `candidate`. The 584-bar holdout returned `12.40%`, Sharpe `0.3782`, and max drawdown `-23.52%`; PIT, observation count, and positive raw holdout Sharpe checks passed. Advisory failures were breadth-deflated holdout Sharpe (`0.3782 < 2.2371`), DSR evidence (`0.4256 < 0.95`), bootstrap lower confidence (`0.0360 < 0.95`), regime robustness (one regime Sharpe `-0.9998`), and idiosyncratic alpha (`-0.0415 < 0.3`).

Verdict: discarded. Despite positive walk-forward windows and a binding gate pass, the holdout degraded materially from walk-forward, retained a large drawdown, had no positive idiosyncratic alpha, and failed badly in one volatility regime. The independent interpretation call judged this insufficiently robust beyond the measured search.

## 2. Distributed-loss peer selloff rebound

Strategy: `distributed_loss_peer_selloff_rebound`

Hypothesis: peer-relative multi-session selloffs rebound more reliably when downside is spread across several sessions rather than concentrated in a single event-style daily loss. The signal penalizes normalized downside-return concentration.

Base parameters: `selloff_lookback=5`, `concentration_weight=1.0`; `top_k_equal_weight` with `top_k=3`.

Full backtest: total return `191.77%`, CAGR `9.68%`, Sharpe `0.5745`, max drawdown `-36.55%`, turnover `903.17`.

Walk-forward: mean Sharpe `0.5031`, minimum Sharpe `0.2414`, standard deviation `0.2237`, positive windows `100%`. Window Sharpes were `0.2414`, `0.6084`, `0.8142`, and `0.3486`.

Sweep: `selloff_lookback=[4,6]` and `concentration_weight=[0.5,1.0,1.5]`, six measured combinations. The best combination was `selloff_lookback=6`, `concentration_weight=0.5`, with mean Sharpe `0.5736`, minimum Sharpe `0.2496`, and all windows positive. Five of six combinations had all windows positive; mean Sharpes occupied a narrow `0.4753` to `0.5736` range, evidence of useful parameter stability.

Preview gate: binding floor passed and the scratch strategy reached `candidate`. The 584-bar holdout returned `38.72%`, Sharpe `0.8666`, and max drawdown `-16.51%`; PIT, observation count, positive raw holdout Sharpe, and idiosyncratic alpha (`0.7127`) passed. Advisory failures were breadth-deflated holdout Sharpe (`0.8666 < 2.2371`), DSR evidence (`0.8075 < 0.95`), bootstrap lower confidence (`0.2473 < 0.95`), and regime robustness (middle-regime Sharpe `-0.1342`).

Verdict: candidate-preview-pass. The independent interpretation call recommended promotion because the raw holdout was strong, every base walk-forward window was positive, and nearly the entire six-combination grid was stable. The statistical and regime advisories remain material paper-stage risks, so this is a cautious candidate rather than a confirmed edge.

## 3. Thresholded peer selloff conviction

Strategy: `thresholded_peer_selloff_conviction`

Hypothesis: only peer-relative selloffs above an economic threshold should be bought, with stronger selloffs receiving proportionally more weight through `score_proportional_long`.

Base parameters: `selloff_lookback=5`, `min_relative_selloff=0.03`.

Full backtest: total return `13.73%`, CAGR `1.12%`, Sharpe `0.1587`, max drawdown `-53.98%`, turnover `884.22`.

Walk-forward: mean Sharpe `-0.0571`, minimum Sharpe `-0.4462`, standard deviation `0.2432`, positive windows `50%`. Window Sharpes were `0.1175`, `-0.4462`, `-0.0757`, and `0.1761`.

Sweep: `selloff_lookback=[3,5]` and `min_relative_selloff=[0.02,0.04,0.06]`, six measured combinations. The best mean-Sharpe combination was `selloff_lookback=3`, `min_relative_selloff=0.06`, at `0.3444`, but its minimum window Sharpe was `-0.6669`. Every combination had a negative worst window, and trial mean Sharpes ranged from `-0.1491` to `0.3444`.

Preview gate: binding floor passed and the scratch strategy reached `candidate` because the 584-bar holdout returned `52.18%` with Sharpe `0.9983` and max drawdown `-18.83%`. Advisory failures exposed the contradiction: positive windows were only `50%`, minimum window Sharpe was `-0.4462`, breadth-deflated holdout Sharpe failed (`0.9983 < 2.2781`), DSR evidence was `0.8284`, bootstrap confidence was `0.2434`, and the low-volatility regime Sharpe was `-0.3329`.

Verdict: discarded. The isolated strong holdout does not outweigh a negative base walk-forward mean, two losing windows, a `-53.98%` full-period drawdown, and a negative worst window in every swept combination. The independent interpretation call treated this as unstable rather than promotable.

## Summary

Only `distributed_loss_peer_selloff_rebound` is named for authoritative merge-back. The evidence supports the thesis more when the signal distinguishes the *shape* of a selloff than when it simply increases exposure with selloff magnitude. The hard shock veto was stable before holdout but failed idiosyncratic and regime tests; thresholded conviction was chronically unstable despite a favorable final holdout.
